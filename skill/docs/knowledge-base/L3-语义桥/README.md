> 抹平"设计/协议"和"代码"的鸿沟。产品语言 → 代码指令的翻译层。

## 目录

| 文件 | 用途 |

## 核心问题

> **真正的提效不在"AI 写代码"，而在"AI 不再需要人来当翻译"。**

### 5 个翻车点

| # | 翻车点 | 真实场景 | 代价 |
|---|--------|----------|------|
| 1 | 范围错判 | PRD 段落讲后端，中间一句移动端被忽略 | 漏实现 |
| 2 | 归宿不明 | 9 张设计稿 AI 只挑 2 张 | 漏 7 个页面 |
| 3 | 联想扩大 | 用户说"点 A 拦截"，AI 联想"B 也应该拦" | 越界 |
| 4 | 关键词找不到 | 直接 grep "小红条" → 0 命中 | 定位失败 |
| 5 | 找错文件 | "邮件红点"翻译错位置 | 功能走错地方 |
