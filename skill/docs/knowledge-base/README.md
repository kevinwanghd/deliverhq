# 知识库（Knowledge Base）

> 来源：企业微信团队"AI代码生成率94%"经验。
> 核心原则：**AI 提效的天花板，既在模型，也在工程。references/ 比 tools/ 体量更大。**

## 三级金字塔结构

```
L1-项目总览/     ← AI 入场的"大堂导览"（< 5KB）
L2-模块级/       ← 文件粒度的"街道地图"
L3-语义桥/       ← 抹平"设计/协议"和"代码"的鸿沟
```

## 快速使用

### 五步定位法（结合知识库使用）

1. 从 L1 总览里 1 秒选出模块（不用 grep）
2. 从 L2 模块 wiki 里 5 秒锁定文件（不用读源码）
3. 进入文件后 rg 精准搜索
4. 只读相关片段（~10K token）
5. 写代码前先查 L3 映射表

**总 token 消耗：从"全项目灌入"的 ~10M+ 降到 ~30K — 300× 的压缩比。**

## 副作用

> **这套知识库对人类新人同样有用。** "AI 友好"和"新人友好"完全统一了——新人直接读 overview.md 加几份模块 wiki，半天就能上手改 bug，不再需要"找老人聊一上午"。
