# 验证阶段红线（verify）

> 加载时机：进入「验证」阶段时
> 违反后果：带病上线，视觉还原度不达标

---

## RL-S05：视觉对齐必须逐项核对

### 规则

> UI 改动必须逐项核对数值，未对齐 ≥ 1 → FAIL

### 核对清单

| 核对项 | 设计稿值 | 实现值 | 状态 |
|--------|----------|--------|------|
| container.height | 280px | 280px | ✅ |
| icon size | 96×96 | 96×96 | ✅ |
| title 字号 | 16/Medium | 16/Medium | ✅ |
| padding | 16px | 16px | ✅ |
| 颜色 | #333333 | #333333 | ✅ |

### 数值类型核对

- **尺寸**：container 高度、icon 大小、间距
- **字体**：字号、字重（Regular/Medium/Bold）
- **颜色**：HEX 值、RGBA 值
- **文字**：文案内容（检查 i18n key 对应值）

### 禁止行为

- "差不多就行" → **严格对齐**
- "这个细节用户看不出来" → **必须对齐**
- 设计稿说 280px，实际写 260px

# 3. 截图比对
screenshot对比：✅ 完全一致
